フラッシュメッセージの導入

【フラッシュメッセージとは】  
フラッシュメッセージはウェブアプリなどで一時的に通知などを表示するための仕組み。  
例えばユーザー登録などを行うと画面上部に「登録完了」と表示させるなど。  


【add_flash_types】controller  
フラッシュメッセージを追加するためのメソッド。  
applicationcontrollerにてキーを定義する。  
add_flash_typesに続けてキーを入力する。  
例) add_flash_types :success, :danger  
フラッシュメッセージを表示したいアクションの中で、  
指定したキーと表示するメッセージを入力する。  
```
  def create
    @user = User.new(user_params)
    if @user.save
      redirect_to root_path, success: 'ユーザー登録が完了しました'
    else
      render :new
    end
  end
```  
その後view側で上記のキーとメッセージのメッセージ部分だけを表示させる。
