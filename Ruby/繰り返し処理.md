繰り返し文基礎

【while文】  
PHPと同じく、決められた条件が真の間中処理を行い続ける。  
例文）  
```  
i = 1

puts "繰り返し処理を開始します"
while i <= 5
  puts "#{i}回目"
  i += 1
end
puts "繰り返し処理を終了しました"  
```  
上記はiが5以下の場合処理をし続ける。  

【timesメソッド】  
timesメソッドは回数をあらかじめ指定しておき、  
指定した回数だけ繰り返し処理を行う。  
例文）  
```  
5.times do |i|
  puts "#{i + 1}回目"
end  
```  
上記では5を指定しているので、5回繰り返し処理を実行する。  

【each文】  
最重要。配列やオブジェクトの要素を一つずつ取り出して、  
繰り返し処理を行う。  
例文）  
```  
(1..5).each do |i|
  puts "#{i}回目"
end  
```  
[出力結果]  
```  
1回目
2回目
3回目
4回目
5回目
```  
上記では1から5までのオブジェクトを作成しており、  
その要素を一つとりだし、変数iに格納している。  
1を取り出し終えると、オブジェクトは2になり、iに2が格納される。
