●条件文    
【if文の基礎】
基本的に他言語と同じく、ifのあとに条件を続けて、  
trueの場合の処理を記載する。  
falseの場合に処理が必要な場合は、elseで処理内容を記述する。  
if文はendで閉じること
例文）  
```  
number = 3

if number > 5
  puts "この数値は5より大きいです"
else
  puts "この数値は5以下です"
end  
```  

【elsif】  
ifでfalseとなった際に、さらに条件を付けたしで、分岐を行う場合に使用する。elseifでは無い点に注意  
例文）  
```  
number = 5

if number > 5
  puts "この数値は5より大きいです"
elsif number == 5
  puts "この数値は5です"
else
  puts "この数値は5より小さいです"
end  
```  

●case文  
【case文の基礎】  
case文は条件を複数定義して合致した条件の処理を行う制御構文。  
Whenで条件を並べる。  
例文）  
language = 'Ruby'

```  
language = 'Ruby'

case language
when 'Ruby'
  puts '私はRubyistです'
when 'Python'
  puts '私はPythonistaです'
when 'PHP'
  puts '私はPHPerです'
else
  puts '私はプログラマーです'
end  
```  
この文章ではlanguageにRubyが入っているため、  
Whenで並べられたうちの一番上の処理が実行される。  
case文は「上から順番に評価され、最初にマッチした条件で処理が終わる」という仕組みなので優先順位が高いものが上にくる。
