例外

【例外とは】
プログラムが実行中に発生するエラーや異常な状態のこと。


【例外処理】  
エラーが起きそうな部分にエラーになった場合の処理を記述して置き、  
エラーが発生した際エラーを検知し、適切な処理を目指す。  
「begin」と「rescue」を使用する。  
「begin」ブロック内にエラーが発生する可能性のある処理を記述しておき、  
「rescue」で例外が発生した場合の処理を記述する。  
例文）  
```  
begin
  1 / 0
rescue ZeroDivisionError => e
  puts "ZeroDivisionError: #{e.message}"
end  
```  
上記例では、beginに1/0という計算を記述して、  
意図的にエラーを発生させる。  
エラーになった場合の処理でrescueでエラー内容を出力させる。  
ちなみに）  
"ZeroDivisionError"はRubyに備わっているオブジェクトで、エラー内容の定型文字列を持つインスタンスを生成している。  
少しわかりにくいが、端的に言うと、エラー内容の定型文をeという変数に格納していると考えればよい。  
参考）他の例外の例  
| 例外の種類 | 説明 |
|-----------|------|
| NoMethodError | メソッドが存在しない場合に発生します。 |
| NameError | 変数や定数が存在しない場合に発生します。 |
| SyntaxError | 構文エラーが発生した場合に発生します。 |
| ArgumentError | メソッドに対して不正な引数が渡された場合に発生します。 |  

【正規表現】  
正規表現とは自分でパターンを作成して、そのパターンに合致しているか検索したり、削除したりする。  
何を言っているかわからないかもしれないので、例文を見て考える。  
例文）  
```  
pattern = /Ruby/

puts "Ruby".match(pattern)
puts "Python".match(pattern)
``` 
上記の文章では、まずRubyというルール(基準)をpatternに格納している。  
注意したいのが変数に値を格納しているわけではないということ。  
そして""で囲まれた文字列に対して、  
自分の設定したルール(Ruby)がどのように関係しているのかを検証している。  
今回はmatchメソッドを使用しているので合致しているかを確認している。  
//はルールを指定する際のはじめとおわりを示している。
