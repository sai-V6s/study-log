モジュール

【モジュールとは】  
定数やメソッドを複数あらかじめ記述して置き、  
クラスなどで読み込むことで記述して置いたメソッドを使えるようにさせる。  
これにより複数のクラスで同じメソッドを使用したいときに楽。  
外部からモジュールファイルを読み込むこともできる。   

※モジュール名の頭文字は大文字にしなければいけない。

【モジュールの定義】
「module」をキーワードに定義する。  
例文）  
```  
module Ultimate
    def DRAGONBALL
        "KAMEHAMEHA"
    end
end
```
このモジュールを読み込むことで、  
自分でメソッドを定義したことになる。  

【モジュールを読み込む(include)】  
```  
module Ultimate
    def DRAGONBALL
        "KAMEHAMEHA"
    end
end

class JUMPHero
    include ultimate
end

```  
事前にモジュールで定義して置いたDRAGONBALLメソッドを使用できるようになる。  

【モジュールを読み込む(extend)】  
モジュールで定義しておいたメソッドをクラスメソッドとして使用できる。  
```  
module Ultimate
    def DRAGONBALL
        "KAMEHAMEHA"
    end
end

class JUMPHero
    extend Ultimate
end
```  
補足）クラスメソッドの利点は？  
メソッドでインスタンスを作成したいときなどに便利。  
いちいちnewでインスタンスを作るのは手間なので、  
メソッドとしてnewする処理を行わせる。  
newはクラスによるメソッドでインスタンスのメソッドでは使用できない。  

【定数もモジュールに入れて置ける】  
定数（キーワードと連動させておく値のようなもの）もメソッドと同じくモジュールに記述して置ける。  
例文）  
```  
```  
module Ultimate
    KAKALOT = "KAMEHAMEHA"
end

class JUMPHero
    include Ultimate
end

goku = JUMPHero.new
puts Ultimate::KAKALOT
```  
[出力結果]  
KAMEHAMEHA
