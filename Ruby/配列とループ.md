配列とループ

例）配列の形式で引数を受け取れるcashierという関数を作成して消費税込みの合計金額を計算するプログラムを作成する  
例文）  
```  
def cashier(prices)
  sum = 0
  prices.each do |price|
    sum += price
  end
  puts "#{(sum * 1.1).floor}円"
end

cashier([100, 200, 300])  
```  

ひとつづつ例文を解釈する。  
1行目では、引数をひとつ受け取る関数を定義している。  
2行目では、sumという変数を初期化している  
3行目のeachによって引数の中の値をひとつ取り出して、priceという変数に格納する。  
doはその変数を使って行う処理を記載する。endで処理を閉じる。  
4行目ではsumという変数に次々priceを足している。eachは与えられた配列が終わるまで処理を続ける。  
6行目では"#{}"で囲むことによって{}内の結果を文字列として出力している。（式展開）
