関数と引数

【関数】  
定義：「def」に続けて関数名を記述する。()で引数を指定できる  
例文）  
```  
def greet(message)
  puts message
end  
```
呼び出し：関数名をそのまま使うことで呼び出せる。引数が必要であれば関数名に続けて引数を入力する。  
`greet("Hello World")`：これだけで関数を呼び出せる。  

【引数と戻り値】  
・引数：関数に渡す値  
・戻り値：関数が処理を終えた後に返す値「return」を使って戻り値を指定する。  
例文）  
```  
def square(num)
  return num * num
end
puts square(5) # 25 と出力されます。  
```  
補足）putsとreturnの違い。  
putsは値を出力する。  
returnは戻り値を返すために用いるもの。  
例文）  
```  
def calculate_sum(a, b)
  return a + b  # 計算結果を返す
end

result = calculate_sum(3, 4)  # 関数からreturnされた値をresultに格納
puts result  # resultを出力
```  

【デフォルト引数】  
デフォルト引数を記述しておくと、引数が渡されなかった場合に引数としてデフォルトで使用される値を指定できる。  
デフォルト引数は引数に =デフォルト引数　で記述する。  
例文）Guestがデフォルト引数として渡される。  
```  
def greet(name = "Guest")
  puts "Hello, #{name}!"
end

greet
```  
[出力結果]  
Hello,Guest!  


【可変長引数】  
可変長引数を使用すると、複数の引数をメソッドに渡すことができる。  
引数が定まっていない場合に使用する。  
引数部分に「*」で指定できる。  
例文）  
```  
def greet(*names)
  names.each do |name|
    puts "Hello, #{name}!"
  end
end

greet("Alice", "Bob", "Carol")  
```  

【キーワード引数】  
キーワード引数は、引数にキーワードを設定しておき、  
引数をメソッドに渡す際にキーワードを指定すると値をどの引数に渡すか指定できる。  
定義は、(キーワード:)のように「:」を付ける。  
例文）  
```
def greet(name:, age:)
  puts "Hello, I am #{name}!"
  puts "I am #{age} years old."
end

greet(age: 20, name: "Alice")
```  
上記は、「age」と「name」をキーワードにして関数を呼び出している。  

【スコープについて】  
メソッド内で定義された変数は、そのメソッド内でしか参照できない。  
例文）  
```  
def greet
  message = "Hello, Ruby!"
  puts message
end

greet
puts message
```  
この場合、変数「message」を表示させようとしているが、  
メソッド内で定義された変数の為エラーとなってしまう。  

【関数による演算】  
例）2つの引数を受け取れるcashierという関数を作成して消費税込みの合計金額を計算する。(消費税以下は切り捨てるようにすること。)  
例文）  
```  
def cashier(price1, price2)
  puts ((price1 + price2) * 1.1).floor
end

cashier(100, 200)  
```  
floorメソッド→計算結果の小数点以下を切り捨てて、整数を返す。
