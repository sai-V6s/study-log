配列とループ
●配列の基礎  

配列の定義：以下のように定義する。  
配列名 = []  
例文）  
```  
mixed_array = [1, "two", 3.0, [4, 5], {six: 6}]  
```  
配列にはハッシュや数値など様々な型のオブジェクトを格納できる。  

【配列の要素（インデックス）へのアクセス方法】  
PHP同様、配列名[0]からスタートし、  
puts 配列名[1]のように[]内に要素番号を指定する。  
補足）負のインデックス  
配列名の要素に-を付けると、配列の最後から要素を取得できる。  

補足②）  
範囲（Range）を使って配列の一部の要素を取り出せる。  
配列名[1..3]→1~3の要素を取得する

【配列の要素の追加】  
配列の要素の追加は様々方法がある。  
①「push」メソッド。配列の末尾から追加できる  
配列名.push("追加する要素名")  
`fruits.push("cherry")`  
②「<<」メソッド。pushと同様末尾に追加。  
配列名 << "追加する要素名"  
`fruits << "cherry"`  
③unshiftメソッド。配列の先頭から追加    
配列名.unshift("追加する要素名")  
④insertメソッド。指定した要素番号に追加する。    
配列名.insert(要素番号,"追加したい要素名")  
`fruits.insert(1,"cherry")  

【要素の削除】  
①popメソッド。配列の末尾から削除する  
配列名.pop  
`fruits.pop`  
②shiftメソッド。配列の先頭から削除  
配列名.shift
`fruits.shift`  
③deleteメソッド。要素を指定して削除する。  
配列名.delete("削除する要素名")  
`fruits.delete("banana")`  
④delete_atメソッドで要素番号を指定して削除する。  
配列名.delete_at(削除する要素番号)  
`fruits.delete_at(1)`  

【配列の要素の変更】  
indexを使用して要素を変更する  
配列名[変更したい要素番号] = "変更後の要素名"  
指定した要素番号内の値が変更される。  
`fruits[1] = "avocado"  

【配列を使った繰り返し処理】  
・eachメソッド  
eachメソッドは配列の各要素に対して繰り返し処理を行うメソッド。  
処理の内容は「do ~ end」または「{ ~ }」で定義し、  
引数にはブロック(||で囲んだ配列の要素を格納するための新しい変数)を渡す。  
例文）indexに回数を格納し、回数と要素名を出力するプログラム  
```  
fruits = ["apple" , "banana" , "cherry"]  

fruits.each do |fruits|
    puts fruits
end  
```  
補足）indexを使ったeachメソッド   
each_with_index 何回繰り返したかを確認できるメソッド  
```  
fruits = ["apple" , "banana" , "cherry"]  

fruits.each_with_index do |fruits,index|
    puts "#{index}: #{fruits}"
end
```  

例）配列の形式で引数を受け取れるcashierという関数を作成して消費税込みの合計金額を計算するプログラムを作成する  
例文）  
```  
def cashier(prices)
  sum = 0
  prices.each do |price|
    sum += price
  end
  puts "#{(sum * 1.1).floor}円"
end

cashier([100, 200, 300])  
```  

ひとつづつ例文を解釈する。  
1行目では、引数をひとつ受け取る関数を定義している。  
2行目では、sumという変数を初期化している  
3行目のeachによって引数の中の値をひとつ取り出して、priceという変数に格納する。  
doはその変数を使って行う処理を記載する。endで処理を閉じる。  
4行目ではsumという変数に次々priceを足している。eachは与えられた配列が終わるまで処理を続ける。  
6行目では"#{}"で囲むことによって{}内の結果を文字列として出力している。（式展開）
