オブジェクト指向の実践-コードではどう書く？  

【クラスの定義】  
「class　クラス名」と「end」で囲む  
例文） 
```   
class Hero  
end  
```  

【インスタンスの生成】  
クラス名.newでインスタンスを生成できる。  
例文）  
```  
class Hero  
end

NARUTO = Hero.new
```  

【クラスに操作(メソッド)を定義する】  
クラス内でdefを用いてユーザー定義メソッドを作成する。  
例文）  
```  
class Hero
    def ultimate
    "RasenGan"
    end
end

NARUTO = Hero.new
puts NARUTO.ultimate
```
[出力結果]  
RasenGan  

【属性の指定(initialize)】  
initializeメソッドでクラスの属性を指定できる。  
例文）  
```  
class Hero  
    def initialize(name,born)  
        @name = name
        @born = born
    end
end

Hero1 = Hero.new("NARUTO","KONOHA")
Hero2 = Hero.new("LUFI","EASTBLUE")
```  
上記のようにインスタンスを生成する際に引数を渡すことで、  
属性を追加できる。

【インスタンス変数(@)】  
インスタンス変数はインスタンスごとに異なる値を保持するときに使用する。上記では、Heroの名前と出身地は異なるのでインスタンス変数を利用する。  

【ゲッターとセッター】  
・ゲッター：インスタンス変数の値を外部から取得するためのメソッド。  
例文）  
```  
class Hero  
    def initialize(name,born)  
        @name = name
        @born = born
    end

    def name
        @name
    end
end
Hero1 = Hero.new("NARUTO","KONOHA")  
puts Hero1.name
```  
クラス内でゲッターを定義しておくことで外部から閲覧できる。  
・セッター：インスタンス変数の値を外部から変更する。  
例文）  
```  
class Hero  
    def initialize(name,born)  
        @name = name
        @born = born
    end

    def name
        @name
    end

    def name=(name)
        @name = name
    end
end
Hero1 = Hero.new("NARUTO","KONOHA")  
Hero1.name = "SASUKE"  
puts Hero1.name  
```  
上記では、インスタンス変数を上書きする「name=」メソッドを定義している。引数はnameを取る。  
補足）メソッド名では「name」と「=」がつながっているが、  
呼び出しの際は空白がある。これはRubyではセッターのメソッドはこう書くものという習わしのようなもの。  
呼び出しの際=を詰めてもエラーにはならない。  

【ゲッター、セッターの簡易化】  
文頭にattr_accessorで触れるインスタンス変数を設定しておくと、  
事前にdefでメソッドを定義せずにアクセス可能になる。  
例文）  
```  
class Hero  
    attr_accessor :name, :age

    def initialize(name,born)  
        @name = name
        @born = born
    end

end
Hero1 = Hero.new("NARUTO","KONOHA")  
Hero1.name = "SASUKE"  
puts Hero1.name  
```  
これだけで、メソッドを定義したことになる。  

【クラスメソッド】  
クラスメソッドは指示書のようなもので、インスタンスからは呼び出せない。(登場人物が指示を出せない)  
クラスから呼び出しを行う。クラスメソッドはメソッド定義の際に、「self.」をメソッドの文頭に付けることで定義できる。  
例文）  
```  
class Hero  
    attr_accessor :name, :age

    def initialize(name,born)  
        @name = name
        @born = born
    end

    def self.introduce
        "Hello JUMP"
    end
end
Hero1 = Hero.new("NARUTO","KONOHA")    
puts Hero.introduce
```  
この場合、Heroというクラスがメソッドを実行している。  
Heroはインスタンス変数の内部のことはスコープ外なので、  
メソッド内に#{name}のように記述してもエラーになってしまう。  

【privateメソッド】  
クラス（設計図）のみで使用できるメソッド。  
外部からメソッドを実行しようとしてもエラーになる。 
「private」をキーワードを記述してからメソッドを定義する。   
例）  
```  
class Hero  
    attr_accessor :name, :age

    def initialize(name,born)  
        @name = name
        @born = born
    end

    private

    def secret
        'プライベート'
    end
end
Hero1 = Hero.new("NARUTO","KONOHA")    
puts Hero1.secret
```  
↑は外部からsecretにアクセスしようとしているのでエラーになります。  
じゃあどうやってsecretの内容を出力させるのか。  
いったんクラス内で別メソッドを経由させて外部からアクセスする。  
例文）  
```  
class Hero  
    attr_accessor :name, :age

    def initialize(name,born)  
        @name = name
        @born = born
    end

    def introduce
        "#{secret}は教えません。"
    end

    private

    def secret
        'プライベート'
    end
end
Hero1 = Hero.new("NARUTO","KONOHA")    
puts Hero1.introduce
```  
上記の場合、introduceに一度secretメソッドの戻り値が格納され、  
introduceメソッドを出力することで、間接的にプライベートメソッドの値を確認できる。
