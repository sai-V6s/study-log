オブジェクト指向の実践-コードではどう書く？  


【クラスの定義】  
「class　クラス名」と「end」で囲む  
例文） 
```   
class Hero  
end  
```  

【インスタンスの生成】  
クラス名.newでインスタンスを生成できる。  
例文）  
```  
class Hero  
end

NARUTO = Hero.new
```  

【クラスに操作(メソッド)を定義する】  
クラス内でdefを用いてユーザー定義メソッドを作成する。  
例文）  
```  
class Hero
    def ultimate
    "RasenGan"
    end
end

NARUTO = Hero.new
puts NARUTO.ultimate
```
[出力結果]  
RasenGan  

【属性の指定(initialize)】  
initializeメソッドでクラスの属性を指定できる。  
例文）  
```  
class Hero  
    def initialize(name,born)  
        @name = name
        @born = born
    end
end

Hero1 = Hero.new("NARUTO","KONOHA")
Hero2 = Hero.new("LUFI","EASTBLUE")
```  
上記のようにインスタンスを生成する際に引数を渡すことで、  
属性を追加できる。

【インスタンス変数(@)】  
インスタンス変数はインスタンスごとに異なる値を保持するときに使用する。上記では、Heroの名前と出身地は異なるのでインスタンス変数を利用する。  

【ゲッターとセッター】  
・ゲッター：インスタンス変数の値を外部から取得するためのメソッド。  
例文）  
```  
class Hero  
    def initialize(name,born)  
        @name = name
        @born = born
    end

    def name
        @name
    end
end
Hero1 = Hero.new("NARUTO","KONOHA")  
puts Hero1.name
```  
クラス内でゲッターを定義しておくことで外部から閲覧できる。  
・セッター：インスタンス変数の値を外部から変更する。  
例文）  
```  
class Hero  
    def initialize(name,born)  
        @name = name
        @born = born
    end

    def name
        @name
    end

    def name=(name)
        @name = name
    end
end
Hero1 = Hero.new("NARUTO","KONOHA")  
Hero1.name = "SASUKE"  
puts Hero1.name  
```  
上記では、インスタンス変数を上書きする「name=」メソッドを定義している。引数はnameを取る。  
補足）メソッド名では「name」と「=」がつながっているが、  
呼び出しの際は空白がある。これはRubyではセッターのメソッドはこう書くものという習わしのようなもの。  
呼び出しの際=を詰めてもエラーにはならない。
