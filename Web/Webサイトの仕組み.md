# Webサイトの仕組み

Webサイトが表示される仕組み

【Webサイトの基本】  
URLを入力した際に、後ろ側では何が起こっているのか。  
URLをクリックすると、クライアント（ユーザーのPC）側からWEBサーバーへとリクエストが送られる。  
リクエストを受けとったサーバーはIPアドレスを辿り、DNSサーバーへリクエストをたらい回しにする。  
必要なファイルをかき集め、レスポンスとしてクライアントへ返す。  
レスポンスを受け取ったクライアントはHTMLやJPGを解析し、WEBサイトを出力する。  
このような一連の動きを**クライアント・サーバーモデル**という  
補足）簡略化されて、リクエストが直接Webサーバーに行くように見えるが、  
実際は中継役となる、DNSサーバーというサーバーがURLのドメインからwebサーバーのIPアドレスを割り出してリクエストをWebサーバーへ送ってくれている。

![サーバークライアントモデル.jpg](../images/serve-cliant-model.jpg)  

【動的サイトの場合】  
上記のブラウザ→サーバー→ブラウザといった一連のやり取りは、  
静的サイトに見られる動きであり、動的アプリの場合動きが異なる。  
リクエストを受け付けるとそのリクエストはMVCモデルを持ったサーバーに引き渡されます。  
MVCモデルで処理を行った後、レスポンスとしてブラウザへ返される。
