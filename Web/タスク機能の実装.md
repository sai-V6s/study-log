タスク機能の実装

【タスクテーブルとタスクモデルを作成】  
タスクテーブルを作成するにあたり、  
まずマイグレーションファイルとタスクモデルの作成が必要になる。  
カリキュラムではDcokerコマンドを実行して作成
`docker compose exec web rails generate model Task`  

【マイグレーションファイルの編集】  
テーブルの作成に伴い、必要なテーブルのカラムを追記していく。  
編集がすんだらマイグレーションファイルを適用する。  

【ルーティングの設定】  
config内のルーティングファイルを修正する。  
Taskは複数のリソースになるためresouresを使用する。  

【コントローラの作成】  
まずdockerコマンドにより、アクションが記述されていないコントローラの枠を作成する。  
`docker compose run web bin/rails generate controller tasks`  
作成したコントローラ枠内にタスクのメソッドを追記していく。  
メソッドは一覧表示、詳細表示、作成、編集、削除の処理を記述する。(ユーザー表示画面と類似している)  

【ビューの作成】  
上記の処理一つ一つにビューを作成する。  
作成に際してdockerコマンドを実行してビューファイルを作る。
