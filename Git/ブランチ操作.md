ブランチ操作

【ブランチ操作】  
ブランチ操作では以下のようなことができる。  
```  
ブランチの作成
ブランチの切り替え
ブランチの一覧表示
ブランチのマージ
ブランチの削除
```  
●ブランチの作成：git branch <ブランチ名>  
●ブランチを一覧表示：git branch  
●ブランチの切り替え：git checkout <ブランチ名>  
補足）ブランチ作成と同時に切り替えを行う。  
git checkout –b <ブランチ名>  
●ブランチのマージ：git merage <マージ元のブランチ名>  
●ブランチの削除：git branch -d <ブランチ名>
