#レイアウト作成の流れ

1.基本構造の準備  
　head～footerまで枠組みを定義する。  
　vs codeであればhtml:5を選択して自動で記述してくれる。  
2.メインコンテンツのレイアウト設計  
　メインコンテンツはdivタグで各領域を作成する。  
　各領域では角丸や中央寄せパディングなどで大雑把な見栄えを決定する  
3.画像などの配置  
　画像やイラストなどを配置する  
4.細かな文章を記述  
　 `<p>`タグなどを用いて文章を作成していく。  
　flexboxなどのプロパティで文章を横並びにしたり配置にも気を配る。  
ex.フレームワークでの記述  
　フレームワークを使って記述すると上記の内容をより簡潔に記述できる。
