HTMLの基礎

・HTMLは<!DOCTYPE html>からはじまり、<html></html>タグで囲まれた文章で構成されている
　文章内では「タグ」と呼ばれるものにより、ブラウザ上に表示される要素を定義する。
　主要なタグは様々あるが、特に利用されるタグを列挙する
　・<h1>～<h6>：見出しをを表示するタグ
　・<P>：見出し内の文章や段落を表現するタグ
　・<a>：ハイパーリンクを作成するタグ。外部サイトに遷移する際などに使用
　・<div>要素の一つ一つの領域をグループ化するためのタグ
　・<form>フォームを作成するタグ
　・<input>フォームの入力フィールドを作成するタグ
・HTMLのコメントアウト
　HTMLではコメントアウトする際は「,!--」「-->」で囲った範囲をコメントアウトできる。
・HTMLの構成
　HTMLは基本、head/main-header/footerで構成されている。
　head：Webページに直接表示される内容ではなく、使用するレイアウト
　main：Webページのヘッダーにあたる部分や、Webページのメインコンテンツとなる部分を記述する
　footer：アクセスや連絡先、権利などを記述する部分。
