CSSのフレームワーク

フレームワークはWebデザインのスタイルやレイアウトを効率的に実装する機能
今回はTailwindというフレームワークをもとに学習する

【フレームワークの読み込み】  
読み込みには基本的にCDNと呼ばれる方法とnpmと呼ばれる方法がある。  
今回はCDNでの読み込みを行う。  
headのscriptタグ内にフレームワークのパスを記述する  
例）  
`<head>`  
  `<script src="https://cdn.tailwindcss.com"></script>`  
  `</head>`  
Tailwind CSSの使い方  
フレームワークを読み込んだのち、フレームワークが持っている対応するプロパティをタグ内に入力する。  
例）テキストサイズの変更  
`<p class="text-sm">Small Text</p>`  
`<p class="text-lg">Large Text</p>`  
`<p class="text-3xl">Extra Large Text</p>`

【フレームワークを使用するメリット】  
上記を見ると、フレームワークのオリジナルのプロパティでも、
手打ちしなければいけないのであれば、標準のCSSで記述すればよいのではないか。と疑問が生まれるかもしれない。  
【メリット】  
①フレームワークを使うと長文にならなくて済む。  
標準の場合）  
.title {  
  　font-size: 1.875rem;  
  　font-weight: bold;  
  　text-decoration: underline;  
  　margin: 2rem;  
  }  
`<h1 class="title">Hello, Tailwind!</h1>`  
フレームワークの場合）  
`<h1 class="text-3xl font-bold underline m-8">Hello, Tailwind!</h1>`  
同じ内容でもプロパティが簡潔になっている分、記述しやすい。  
②HTML内だけで完結  
基本はHTMLにクラス名を命名して、それに対応したクラスのプロパティをCSSファイル側で修正する。という作業が必要だが、フレームワークではHTMLだけでプロパティの設定が完結する。  
③命名不要  
②と重複するが、HTMLのタグ内に直接記述することでクラス名を命名する必要がない。  
④保守性
画面の要素が多くなると、その分CSSファイルも大きくなり管理が難しくなるが、HTML内のタグにフレームワークを直接記述することで保守性が向上する。  
【デメリット】  
・同じタグ内に複数タグがあった場合、一つ一つのタグにプロパティを設定する必要がある  
例）`<div>`タグ内に`<p>`タグが三つあった場合、3回プロパティを記述する必要がある。  
・プロパティが多くなればなるほど、文書が長くなり可読性が落ちる  
【解決策】  
①コンポーネント化  
今後学習する中でコンポーネントという仕組みを利用して解決できる。  
これは「プロパティが設定されている`<P>`タグ」というものを一まとまりにして管理できる機能。  
これにより、まとまりを修正することで各`<p>`タグのプロパティを修正できる。  
②@applyでまとめる  
上記のコンポーネント化だけでは対応できない場合、  
CSS側で独自のクラス名を定義して、その中でTailwindのユーティリクスを@applyでまとめる方法。  
例文）h1～h3タグの.markdown-bodyのクラス部分に対して、  
@applyでプロパティをまとめて設定している。  
@layer components {  
    .markdown-body h1,  
    .markdown-body h2,  
    .markdown-body h3 {  
      @apply font-bold mt-1 mb-1;  
      　}  
      }

【参考】  
フレームワークでのクラス課題のなかで、`<footer>`タグにクラスを追加して文字列を中央寄せにしなさいという問題があった。  
通常のCSSではクラスは.contentのように自分で命名して、そのクラス名を使用して別CSSファイルにプロパティを設定していた。  
しかし、フレームワークでは、タグ内のクラスに「text-center」という決まったワードでクラスを命名することで、自動的に定型のクラス名に紐づいたプロパティを設定してくれる。  
例文）「text-center」というクラス名だ！  
　　　　→中央寄せのプロパティを呼び出そう  
`<footer class="text-lg font-bold text-stone-500 text-center">`
